# SentenceTransformer based on sentence-transformers/all-MiniLM-L6-v2

This is a [sentence-transformers](https://www.SBERT.net) model finetuned from [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2). It maps sentences & paragraphs to a 384-dimensional dense vector space and can be used for retrieval.

## Model Details

### Model Description
- **Model Type:** Sentence Transformer
- **Base model:** [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) <!-- at revision 1110a243fdf4706b3f48f1d95db1a4f5529b4d41 -->
- **Maximum Sequence Length:** 256 tokens
- **Output Dimensionality:** 384 dimensions
- **Similarity Function:** Cosine Similarity
- **Supported Modality:** Text

```
SentenceTransformer(
  (0): Transformer({'transformer_task': 'feature-extraction', 'modality_config': {'text': {'method': 'forward', 'method_output_name': 'last_hidden_state'}}, 'module_output_name': 'token_embeddings', 'architecture': 'BertModel'})
  (1): Pooling({'embedding_dimension': 384, 'pooling_mode': 'mean', 'include_prompt': True})
  (2): Normalize({})
)
```

## Usage

### Direct Usage (Sentence Transformers)

First install the Sentence Transformers library:

```bash
pip install -U sentence-transformers
```
Then you can load this model and run inference.
```python
from sentence_transformers import SentenceTransformer

# Download from the 🤗 Hub
model = SentenceTransformer("sentence_transformers_model_id")
# Run inference
sentences = [
    "Detail-oriented Results-driven Database Administrator with 6 years building and maintaining robust systems. Deep expertise in PostgreSQL, MySQL, Oracle, SQL Server, and backup and recovery. Implemented performance tuning solutions that reduced deployment time and increased reliability. Comfortable working with replication and database security in production-grade environments. Known for strong problem-solving skills and clear communication with stakeholders. Experienced in agile methodologies, code reviews, and documentation. Familiar with indexing and high availability, contributing to architecture decisions and technical roadmaps. Bachelor's degree in Information Technology. Track record of mentoring team members and driving process improvements. Enjoys tackling challenging technical problems and delivering measurable business impact through technology.",
    "About the role: Join our team as a Database Administrator responsible for architecting and maintaining critical systems. Required qualifications include 6+ years of experience in PostgreSQL, MySQL, and Oracle. You will design SQL Server solutions, troubleshoot production issues, and collaborate with backup and recovery teams. Proficiency in performance tuning, replication, and database security is required. Experience with indexing and high availability is highly desirable. The successful candidate is detail-oriented, communicates effectively, and enjoys solving complex technical challenges. We offer a collaborative environment, continuous learning opportunities, and a strong focus on work-life balance. Bachelor's or Master's degree in a related technical field is preferred for this position.",
    "We are looking for a talented Android Developer to strengthen our engineering organisation. You will bring 8+ years working with Room, Jetpack Compose, Kotlin, Dagger, Java, Android SDK, Git, REST APIs. Key responsibilities include system design, code reviews, CI/CD pipeline maintenance, and close collaboration with product managers and designers. You will participate in architectural decisions, write comprehensive unit and integration tests, and champion engineering best practices across the team. Strong command of data structures, algorithms, and system design is required. Strong analytical and communication skills are essential. A Bachelor's or Master's degree in Computer Science or a related technical discipline is preferred.",
]
```
